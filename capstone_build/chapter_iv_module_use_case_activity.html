Use Case Diagram

The Use Case Diagram shows the functions that each user can access in the Crime Mapping System. The actors of the system are the Admin, LGU, Police Officer, and Investigator. Each actor is placed outside the system boundary, while the use cases are placed inside the boundary.

Activity Diagram

The Activity Diagram shows the step-by-step workflow of a particular process. It explains what happens from the beginning to the end of a system activity. Unlike the Use Case Diagram, which shows what users can do, the Activity Diagram shows how a process is performed.

Login Module

Login Module Use Case Diagram

Use CaseDescriptionUser/Actor Roles
LoginAllows the user to enter their email and password to access the system.Admin, LGU, Police Officer, Investigator
Reset PasswordAllows the user to request an OTP, verify the code, and create a new password if they forgot their login credentials.Admin, LGU, Police Officer, Investigator
LogoutAllows the user to securely exit the system.Admin, LGU, Police Officer, Investigator

Activity Diagram Workflow:

  1. The system displays the login form.
  2. The user enters email and password.
  3. The system validates the credentials.
  4. If valid, the system displays the dashboard.
  5. If invalid, the system displays an error message.
  6. The process ends.

Crime Incident Management Module

Crime Incident Management Module Use Case Diagram

Use CaseDescriptionUser/Actor Roles
View Crime IncidentsAllows users to view crime incident records. Admin can view all records, police officers can view their reported or assigned records, and investigators can view assigned, pending, or under-investigation records.Admin, Police Officer, Investigator
Report Crime IncidentAllows police officers and admin users to encode a new crime incident, including crime details, barangay, date, time, location, and assigned investigator.Admin, Police Officer
Update Crime IncidentAllows authorized users to edit crime incident details.Admin, Police Officer, Investigator
Update Crime StatusAllows authorized users to change the case status to pending, under investigation, resolved, or closed.Admin, Police Officer, Investigator
Record Investigation FindingsAllows investigators and authorized users to record findings related to the crime incident.Admin, Investigator
Delete Crime IncidentAllows authorized users to remove a crime incident record.Admin, Police Officer, Investigator

Activity Diagram Workflow:

  1. The user opens the Crime Incidents module.
  2. The system checks the user's role and access permission.
  3. The system displays the crime incident list.
  4. The user selects an action: add, view, edit, update status, or delete.
  5. The system validates the submitted information.
  6. If the information is valid, the system saves the record.
  7. The system displays a success message.
  8. If the information is invalid, the system displays an error message.
  9. The process ends.

Evidence Management Module

Evidence Management Module Use Case Diagram

Use CaseDescriptionUser/Actor Roles
Upload EvidenceAllows authorized users to upload evidence files connected to a crime incident.Admin, Police Officer, Investigator
View EvidenceAllows authorized users to view uploaded evidence files.Admin, Police Officer, Investigator
Delete EvidenceAllows authorized users to remove evidence files from a crime incident.Admin, Police Officer, Investigator

Activity Diagram Workflow:

  1. The user opens a crime incident record.
  2. The user uploads or selects an evidence file.
  3. The system validates the file type and file size.
  4. If valid, the system stores the evidence file.
  5. The system links the evidence to the crime incident.
  6. The system displays a success message.
  7. If invalid, the system displays an error message.
  8. The process ends.

Crime Map Module

Crime Map Module Use Case Diagram

Use CaseDescriptionUser/Actor Roles
View Crime MapAllows users to view mapped crime incidents within Koronadal City.Admin, Police Officer, Investigator
Filter Map DataAllows users to filter mapped incidents by crime type, barangay, status, and date range.Admin, Police Officer, Investigator
Detect BarangayAllows the system to detect the barangay based on selected map coordinates.Admin, Police Officer, Investigator
Plot Incident on MapAllows admin and police officers to plot a new crime incident directly on the map.Admin, Police Officer

Activity Diagram Workflow:

  1. The user opens the Crime Map module.
  2. The system loads the map and barangay boundaries.
  3. The user applies filters or selects a location.
  4. The system retrieves matching crime incident data.
  5. The system displays crime markers on the map.
  6. If the user plots an incident, the system validates the incident details.
  7. The system saves the plotted incident and displays it on the map.
  8. The process ends.
