Police Officer Requirements Documentation

Functional Requirements

Login Module

This module allows the Police Officer user to securely access the system using valid credentials.

REQ. PO.1.1 The Police Officer user shall be able to enter their email address.

REQ. PO.1.2 The Police Officer user shall be able to enter their password.

REQ. PO.1.3 The system shall validate the Police Officer user's email and password before granting access to the dashboard.

REQ. PO.1.4 The Police Officer user shall be able to access the forgot password page when needed.

Dashboard Module

This module allows the Police Officer user to view role-based crime summaries.

REQ. PO.2.1 The Police Officer user shall be able to access the dashboard after a successful login.

REQ. PO.2.2 The Police Officer user shall be able to view role-based dashboard statistics.

REQ. PO.2.3 The Police Officer user shall be able to view available crime type, hotspot, trend, and status summary information.

Crime Incident Management Module

This module allows the Police Officer user to record and manage related crime incidents.

REQ. PO.3.1 The Police Officer user shall be able to view crime incidents they reported or are assigned to.

REQ. PO.3.2 The Police Officer user shall be able to create new crime incident records.

REQ. PO.3.3 The Police Officer user shall be able to enter crime details such as title, crime type, offense type, barangay, date occurred, date reported, and address.

REQ. PO.3.4 The Police Officer user shall be able to enter optional details such as time occurred, time reported, stage of felony, latitude, longitude, and investigation findings.

REQ. PO.3.5 The system shall automatically set the Police Officer user as the reporter of the crime incident.

REQ. PO.3.6 The Police Officer user shall be able to upload evidence files when creating or updating a crime incident.

REQ. PO.3.7 The Police Officer user shall be able to search and filter related crime incident records.

REQ. PO.3.8 The Police Officer user shall be able to view full details of related crime incidents.

REQ. PO.3.9 The Police Officer user shall be able to update crime incidents they are authorized to edit.

REQ. PO.3.10 The Police Officer user shall be able to archive crime incidents they are authorized to edit.

Crime Status Workflow Module

REQ. PO.4.1 The Police Officer user shall be able to update the status of authorized crime incidents.

REQ. PO.4.2 The Police Officer user shall be required to enter remarks when changing a crime incident status.

REQ. PO.4.3 The Police Officer user shall be able to view the status history of authorized crime incidents.

Evidence Management Module

REQ. PO.5.1 The Police Officer user shall be able to upload evidence files for authorized crime incidents.

REQ. PO.5.2 The Police Officer user shall be able to view uploaded evidence files for authorized crime incidents.

REQ. PO.5.3 The Police Officer user shall be able to delete evidence files when authorized.

REQ. PO.5.4 The system shall only allow supported evidence file formats such as JPG, JPEG, PNG, PDF, DOC, and DOCX.

Crime Map Module

REQ. PO.6.1 The Police Officer user shall be able to access the crime map.

REQ. PO.6.2 The Police Officer user shall be able to view plotted crime incident locations.

REQ. PO.6.3 The Police Officer user shall be able to view Koronadal City barangay boundaries.

REQ. PO.6.4 The Police Officer user shall be able to detect barangay based on selected coordinates.

REQ. PO.6.5 The Police Officer user shall be able to plot a crime incident from the map.

Hotspot Module

REQ. PO.7.1 The Police Officer user shall be able to access the hotspot module.

REQ. PO.7.2 The Police Officer user shall be able to view crime hotspot information.

REQ. PO.7.3 The Police Officer user shall be able to view crime counts by barangay.

Profile and Logout Module

REQ. PO.8.1 The Police Officer user shall be able to update their profile information.

REQ. PO.8.2 The Police Officer user shall be able to update their password.

REQ. PO.8.3 The Police Officer user shall be able to log out from the system.
