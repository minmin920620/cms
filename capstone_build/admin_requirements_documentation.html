Admin Requirements Documentation

Functional Requirements

Login Module

This module allows the Admin user to securely access the system using valid credentials.

REQ. AU.1.1 The Admin user shall be able to enter their email address.

REQ. AU.1.2 The Admin user shall be able to enter their password.

REQ. AU.1.3 The system shall validate the Admin user's email and password before granting access to the dashboard.

REQ. AU.1.4 The system shall reject invalid login credentials and display an appropriate error message.

REQ. AU.1.5 The Admin user shall be able to access the forgot password page from the login page.

Forgot Password Module

This module allows the Admin user to request password reset assistance when they cannot access their account.

REQ. AU.2.1 The Admin user shall be able to access the forgot password page.

REQ. AU.2.2 The Admin user shall be able to enter their registered email address.

REQ. AU.2.3 The system shall validate the submitted email address before processing the password reset request.

REQ. AU.2.4 The system shall send password reset instructions or a reset code to the Admin user's registered email address.

REQ. AU.2.5 The Admin user shall be able to reset and confirm a new password.

Dashboard Module

This module allows the Admin user to view overall crime records and system statistics.

REQ. AU.3.1 The Admin user shall be able to access the dashboard after a successful login.

REQ. AU.3.2 The Admin user shall be able to view total crime incidents, crimes recorded today, crimes recorded this month, and pending crimes.

REQ. AU.3.3 The Admin user shall be able to view crime statistics by crime type.

REQ. AU.3.4 The Admin user shall be able to view hotspot summary information based on barangay crime counts.

REQ. AU.3.5 The Admin user shall be able to view monthly crime trend information.

REQ. AU.3.6 The Admin user shall be able to view crime status breakdown information.

Crime Incident Management Module

This module allows the Admin user to manage all crime incident records.

REQ. AU.4.1 The Admin user shall be able to view all crime incident records.

REQ. AU.4.2 The Admin user shall be able to create new crime incident records.

REQ. AU.4.3 The Admin user shall be able to enter crime details such as title, crime type, offense type, barangay, date occurred, date reported, and address.

REQ. AU.4.4 The Admin user shall be able to assign a Police Officer as reporter.

REQ. AU.4.5 The Admin user shall be able to assign an Investigator to a crime incident.

REQ. AU.4.6 The Admin user shall be able to search and filter crime incident records.

REQ. AU.4.7 The Admin user shall be able to view, update, and archive crime incident records.

Crime Status Workflow Module

This module allows the Admin user to update and monitor the progress of crime incidents.

REQ. AU.5.1 The Admin user shall be able to update the status of any crime incident.

REQ. AU.5.2 The Admin user shall be required to enter remarks when changing a crime incident status.

REQ. AU.5.3 The Admin user shall be able to record investigation findings.

REQ. AU.5.4 The Admin user shall be able to view the status history of a crime incident.

Evidence Management Module

This module allows the Admin user to manage evidence files connected to crime incidents.

REQ. AU.6.1 The Admin user shall be able to upload evidence files.

REQ. AU.6.2 The Admin user shall be able to view uploaded evidence files.

REQ. AU.6.3 The Admin user shall be able to delete uploaded evidence files.

REQ. AU.6.4 The system shall only allow supported evidence file formats such as JPG, JPEG, PNG, PDF, DOC, and DOCX.

Crime Map Module

This module allows the Admin user to view and plot crime incidents on the map.

REQ. AU.7.1 The Admin user shall be able to access the crime map.

REQ. AU.7.2 The Admin user shall be able to view plotted crime incident locations.

REQ. AU.7.3 The Admin user shall be able to view Koronadal City barangay boundaries.

REQ. AU.7.4 The Admin user shall be able to detect barangay based on selected coordinates.

REQ. AU.7.5 The Admin user shall be able to plot a crime incident from the map.

Hotspot Module

REQ. AU.8.1 The Admin user shall be able to access the hotspot module.

REQ. AU.8.2 The Admin user shall be able to view crime hotspot information.

REQ. AU.8.3 The Admin user shall be able to view crime counts by barangay.

Analytics Module

REQ. AU.9.1 The Admin user shall be able to access the analytics module.

REQ. AU.9.2 The Admin user shall be able to view crime trends, crime by type, crime by barangay, status breakdown, and monthly report data.

Reports Module

REQ. AU.10.1 The Admin user shall be able to access the reports module.

REQ. AU.10.2 The Admin user shall be able to generate report previews.

REQ. AU.10.3 The Admin user shall be able to export reports as PDF files.

User Management Module

REQ. AU.11.1 The Admin user shall be able to view the list of system users.

REQ. AU.11.2 The Admin user shall be able to create new user accounts.

REQ. AU.11.3 The Admin user shall be able to assign user roles.

REQ. AU.11.4 The Admin user shall be able to update user account information.

Maintenance Module

REQ. AU.12.1 The Admin user shall be able to manage crime types.

REQ. AU.12.2 The Admin user shall be able to manage offense types.

REQ. AU.12.3 The system shall use active crime types and offense types when recording crime incidents.

Audit Log Module

REQ. AU.13.1 The Admin user shall be able to access audit logs.

REQ. AU.13.2 The Admin user shall be able to review recorded system activities for accountability and monitoring.

Profile and Logout Module

REQ. AU.14.1 The Admin user shall be able to update their profile information.

REQ. AU.14.2 The Admin user shall be able to update their password.

REQ. AU.14.3 The Admin user shall be able to log out from the system.
