LGU Requirements Documentation

Functional Requirements

Login Module

This module allows the LGU user to securely access the system using valid credentials.

REQ. LU.1.1 The LGU user shall be able to enter their email address.

REQ. LU.1.2 The LGU user shall be able to enter their password.

REQ. LU.1.3 The system shall validate the LGU user's email and password before granting access to the dashboard.

REQ. LU.1.4 The LGU user shall be able to access the forgot password page when needed.

Dashboard Module

This module allows the LGU user to view role-based summary information.

REQ. LU.2.1 The LGU user shall be able to access the dashboard after a successful login.

REQ. LU.2.2 The LGU user shall be able to view role-based dashboard statistics.

REQ. LU.2.3 The LGU user shall be able to view crime summary information available to their role.

REQ. LU.2.4 The system shall prevent the LGU user from accessing crime incident management, crime map, hotspot, report management, user management, audit log, crime type management, and offense type management modules.

Analytics Module

This module allows the LGU user to view crime analytics for planning, monitoring, and decision-making.

REQ. LU.3.1 The LGU user shall be able to access the analytics module.

REQ. LU.3.2 The LGU user shall be able to view crime trend data.

REQ. LU.3.3 The LGU user shall be able to view crime distribution by crime type.

REQ. LU.3.4 The LGU user shall be able to view crime distribution by barangay.

REQ. LU.3.5 The LGU user shall be able to view crime status breakdown information.

REQ. LU.3.6 The LGU user shall be able to view monthly crime report data for a selected year.

REQ. LU.3.7 The system shall restrict LGU access to viewing analytics only and shall not allow LGU users to modify crime records.

Notifications Module

This module allows the LGU user to receive system messages and feedback related to their allowed actions.

REQ. LU.4.1 The LGU user shall be able to view system notifications intended for their role.

REQ. LU.4.2 The system shall display success messages after completed LGU user actions.

REQ. LU.4.3 The system shall display warning or error messages when the LGU user submits invalid information or attempts an unauthorized action.

REQ. LU.4.4 The system shall provide clear notification messages for profile updates, password changes, login errors, logout confirmation, and restricted access attempts.

Profile Module

This module allows the LGU user to manage their account profile and password.

REQ. LU.5.1 The LGU user shall be able to update their profile information.

REQ. LU.5.2 The LGU user shall be able to update their password.

REQ. LU.5.3 The system shall validate profile and password changes before saving.

Logout Module

This module allows the LGU user to securely end their active session.

REQ. LU.6.1 The LGU user shall be able to log out from the system.

REQ. LU.6.2 The system shall invalidate the LGU user's active session after logout.

REQ. LU.6.3 The system shall prevent the logged-out LGU user from accessing authenticated pages without logging in again.
