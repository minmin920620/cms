Investigator Requirements Documentation

Functional Requirements

Login Module

This module allows the Investigator user to securely access the system using valid credentials.

REQ. IU.1.1 The Investigator user shall be able to enter their email address.

REQ. IU.1.2 The Investigator user shall be able to enter their password.

REQ. IU.1.3 The system shall validate the Investigator user's email and password before granting access to the dashboard.

REQ. IU.1.4 The Investigator user shall be able to access the forgot password page when needed.

Dashboard Module

This module allows the Investigator user to view assigned investigation information.

REQ. IU.2.1 The Investigator user shall be able to access the dashboard after a successful login.

REQ. IU.2.2 The Investigator user shall be able to view role-based dashboard statistics.

REQ. IU.2.3 The Investigator user shall be able to view assigned active investigations on the dashboard.

REQ. IU.2.4 The Investigator user shall be able to view the number of assigned active investigations.

Crime Incident Management Module

This module allows the Investigator user to manage assigned crime incidents.

REQ. IU.3.1 The Investigator user shall be able to view crime incidents assigned to them.

REQ. IU.3.2 The Investigator user shall be able to search assigned crime incidents.

REQ. IU.3.3 The Investigator user shall be able to filter assigned crime incidents by crime type, barangay, status, and date range.

REQ. IU.3.4 The Investigator user shall be able to view full details of assigned crime incidents.

REQ. IU.3.5 The Investigator user shall be able to update assigned crime incidents.

REQ. IU.3.6 The Investigator user shall be able to archive assigned crime incidents when authorized.

REQ. IU.3.7 The system shall prevent the Investigator user from viewing or updating crime incidents not assigned to them.

Crime Status Workflow Module

REQ. IU.4.1 The Investigator user shall be able to update the status of assigned crime incidents.

REQ. IU.4.2 The Investigator user shall be required to enter remarks when changing a crime incident status.

REQ. IU.4.3 The Investigator user shall be able to record investigation findings for assigned crime incidents.

REQ. IU.4.4 The Investigator user shall be able to view the status history of assigned crime incidents.

REQ. IU.4.5 The system shall store the old status, new status, remarks, user, and date of every status change.

Evidence Management Module

REQ. IU.5.1 The Investigator user shall be able to upload evidence files for assigned crime incidents.

REQ. IU.5.2 The Investigator user shall be able to view uploaded evidence files for assigned crime incidents.

REQ. IU.5.3 The Investigator user shall be able to delete evidence files when authorized.

REQ. IU.5.4 The system shall only allow supported evidence file formats such as JPG, JPEG, PNG, PDF, DOC, and DOCX.

Crime Map Module

REQ. IU.6.1 The Investigator user shall be able to access the crime map.

REQ. IU.6.2 The Investigator user shall be able to view plotted crime incident locations.

REQ. IU.6.3 The Investigator user shall be able to view Koronadal City barangay boundaries.

REQ. IU.6.4 The Investigator user shall be able to detect barangay based on selected coordinates.

REQ. IU.6.5 The system shall prevent the Investigator user from plotting new incidents from the map.

Hotspot Module

REQ. IU.7.1 The Investigator user shall be able to access the hotspot module.

REQ. IU.7.2 The Investigator user shall be able to view crime hotspot information.

REQ. IU.7.3 The Investigator user shall be able to view crime counts by barangay.

Profile and Logout Module

REQ. IU.8.1 The Investigator user shall be able to update their profile information.

REQ. IU.8.2 The Investigator user shall be able to update their password.

REQ. IU.8.3 The Investigator user shall be able to log out from the system.
